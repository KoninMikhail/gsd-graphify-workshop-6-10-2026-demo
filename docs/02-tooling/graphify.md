# Graphify

Репозиторий — пример корпуса для воркшопа graphify.

## Корпус

В граф позже входит TypeScript из каталогов:

- `apps/`
- `packages/`

Каталог `node_modules` в корпус не входит.

## Состояние в репозитории

- Каталога `graphify-out/` нет: граф ещё не собран.
- Скрипта пересборки графа нет: каталога `scripts/` в репозитории нет.

Вызов CLI и его флаги здесь не описаны: в репозитории нет обёртки и нет сгенерированного вывода, по которым их можно зафиксировать.
