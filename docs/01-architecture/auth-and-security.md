# Аутентификация и доступ

Аутентификации нет. Нет сессий, токенов, паролей, ролей и ключей API. Все маршруты доступны без проверки вызывающего, включая `DELETE /tasks/:id` и `POST /tasks/reset`.

## CORS

В `apps/backend/src/index.ts` плагин `@fastify/cors` зарегистрирован так: `{ origin: true }`. Allowlist origin нет: пришедший `Origin` отражается в ответе.

Опции `methods` и `credentials` приложение не передаёт. Значения плагина по умолчанию: разрешённые методы preflight `GET,HEAD,POST`, `credentials: false`. `PUT`, `PATCH` и `DELETE` в этот список не входят. Прямой вызов этих методов из браузера на другой origin упирается в preflight.

В dev страница открыта на Vite, порт 5173. Запросы идут на `/api/*` того же origin. Прокси пересылает их на `localhost:3001` уже с сервера Vite, поэтому ограничение методов CORS на этот путь не действует.

## Что ещё читает процесс

Из окружения backend берёт только `PORT` (по умолчанию 3001) и `HOST` (по умолчанию `0.0.0.0`). Подписи запросов и хранилища секретов в коде нет.
