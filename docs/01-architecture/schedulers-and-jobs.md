# Планировщик и фоновые задачи

Планировщика нет. Нет cron, очереди заданий, отдельного воркера и повторов по таймеру.

При старте `apps/backend/src/index.ts` один раз, до `listen`, синхронно вызывает `seedIfEmpty()`. Если таблица `tasks` пуста, записываются три демо-задачи. Повтор по расписанию не настроен.

Сброс доски делает кнопка в интерфейсе: один запрос `POST /tasks/reset`. Это не задание планировщика.

Перестановка карточек сохраняется в момент отпускания drag запросом `PUT /tasks/reorder`. Отдельного канала доставки нет: [events-and-realtime.md](./events-and-realtime.md).
