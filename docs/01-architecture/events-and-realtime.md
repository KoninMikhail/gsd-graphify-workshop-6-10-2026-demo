# События и realtime

Канала realtime нет. Нет SSE, WebSocket, брокера сообщений и очереди заданий. Сервер не пушит обновления доски.

Доска меняется в браузере. На сервер уходит обычный запрос.

## Перетаскивание

Код: `apps/frontend/src/App.tsx`. Библиотеки: `@dnd-kit/core`, `@dnd-kit/sortable`. Сенсор — `PointerSensor`, drag начинается после сдвига на 6 пикселей.

Пока карточка находится над другой колонкой (`onDragOver`), меняются только состояние React: статус карточки и место в колонке. HTTP-запроса в этот момент нет.

Когда карточку отпускают (`onDragEnd`):

1. Клиент заново проставляет `position` с нуля внутри каждой колонки.
2. Локальный список сразу показывает этот порядок.
3. `PUT /tasks/reorder` отправляет полный набор `{ id, status, position }`.
4. Ответ сервера (полный `Task[]`) заменяет локальный список.

Если reorder отвечает ошибкой, клиент показывает текст ошибки и заново читает доску через `GET /tasks`.

Создание карточки ждёт ответ `POST /tasks` и добавляет задачу из этого ответа. Удаление сразу убирает карточку из состояния и при ошибке `DELETE` возвращает прежний список.
