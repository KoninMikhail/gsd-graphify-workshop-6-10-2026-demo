Экспорт buildTaskReport(tasks: Task[]): string.
Порядок секций — TASK_STATUSES. Заголовок секции — COLUMN_LABELS[status].
В секции оставить задачи этого status и отсортировать по position по возрастанию.
Задача без пустого description: строка "- " плюс title.
Задача с непустым description после trim: та же строка, пустая строка, затем два пробела и description.trim().
Между задачами одной секции — пустая строка.
Если в секции нет задач, тело секции — ровно *No tasks*.
Весь файл: "# Task Board", пустая строка, секции через "\n\n", в конце один "\n".
В текст попадают только title, description и подписи колонок. Не подставлять id, createdAt, updatedAt.
Не экранировать знаки Markdown: это фаза 2.
Не ветвить пустой массив tasks: пустая доска — фаза 3. Три секции *No tasks* на этом шаге допустимы.
