# Roadmap: gsd-graphify-workshop

## Overview

Снимок `03-milestone` показывает первый продуктовый майлстоун поверх инициализации с ветки `02-gsd-init`. Слушатель читает цель, требования, три фазы и по одному плану на фазу. Код доски тот же: планы не исполнены. Для доски без задач выбран вариант «ошибка, файл не скачивается».

`granularity` в `config.json` остаётся `standard`. Фаз три, не пять–восемь: у майлстоуна три наблюдаемых исхода. Добавлять фазы ради числа нельзя.

## Phases

**Нумерация:**
- Целые номера (1, 2, 3): запланированная работа этого майлстоуна
- Дробные номера сюда не входят: вставок нет

- [ ] **Phase 1: Состав отчёта** - заголовок, три секции в порядке колонок, задачи в сохранённом порядке
- [ ] **Phase 2: Безопасный текст** - знаки Markdown остаются текстом, одинаковые задачи дают одинаковый файл
- [ ] **Phase 3: Пустой отчёт** - пустая доска показывает Nothing to export и не скачивает файл

## Phase Details

### Phase 1: Состав отчёта
**Goal**: Участник получает файл Markdown, в котором текущие задачи разложены по тем же трём колонкам и в том же порядке, что на доске.
**Mode:** mvp
**Depends on**: Ничего (первая фаза)
**Requirements**: RPT-01, RPT-02, RPT-03
**Success Criteria** (что должно быть истинно):
  1. Участник открывает файл и видит заголовок Task Board, затем секции To Do, In Progress и Done.
  2. Участник видит в каждой секции задачи этой колонки по возрастанию `position`, а непустое описание — под заголовком задачи.
  3. Участник видит заголовок пустой колонки, если на доске при этом есть задачи в других колонках.
**Plans:** 1 plan

Plans:
- [ ] 01-01: Собрать текст отчёта и скачать его кнопкой Export markdown

### Phase 2: Безопасный текст
**Goal**: Участник читает заголовки и описания как текст, а повторная выгрузка тех же задач не меняет файл.
**Mode:** mvp
**Depends on**: Phase 1
**Requirements**: RPT-04, RPT-05
**Success Criteria** (что должно быть истинно):
  1. Участник вводит в заголовок или описание знаки Markdown и видит их в файле как символы, а не как заголовок, список, ссылку или код.
  2. Участник дважды выгружает один и тот же набор задач и получает один и тот же текст.
  3. Участник не находит в файле `id`, `createdAt` и `updatedAt`.
**Plans:** 1 plan

Plans:
- [ ] 02-01: Экранировать title и description, не трогая каркас файла

### Phase 3: Пустой отчёт
**Goal**: Для доски без единой задачи действует один заранее записанный вариант, и слушатель может отличить его от пустой колонки при непустой доске.
**Mode:** mvp
**Depends on**: Phase 2
**Requirements**: RPT-06
**Success Criteria** (что должно быть истинно):
  1. Слушатель читает в контексте фазы вариант: баннер Nothing to export, файл не скачивается.
  2. Участник с пустой доской нажимает Export markdown и видит этот баннер, без файла в загрузках.
  3. Пустая колонка при непустой доске по-прежнему оставляет секцию со строкой *No tasks*.
**Plans:** 1 plan

Plans:
- [ ] 03-01: Не вызывать скачивание, если задач нет
